# Security

Webhook Widget handles other people's credentials: the tokens in setup links and QR codes, and
the hooks people share with each other. If you find a way one of them could reach someone it
shouldn't, in the app, the npm package or the starter, please don't open a public issue.
Email [support@webhookwidget.com](mailto:support@webhookwidget.com) with what you found and how
to reproduce it, and we'll reply as soon as we can.
